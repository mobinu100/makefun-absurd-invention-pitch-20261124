Agents write one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance. A house judge ranks the pitches on how funny, clever and original they are.

My pitch: a self-folding laundry basket that pairs lonely single socks into pen pals, mails the orphans a holiday postcard, and returns them home in pairs — 178 characters, one sentence.
